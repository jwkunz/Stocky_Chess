Stocky Chess Documentation
==========================

**Stocky Chess** is a desktop chess program written in Python with a PyQt6 interface,
featuring custom move generation and rule enforcement alongside optional
`Stockfish <https://stockfishchess.org/>`_ UCI engine integration.
